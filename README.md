## Featured project

### Praeco

Praeco is a self-hosted, Telegram-first AI workflow for turning a text or voice
thought into a reviewed LinkedIn post with an original visual.

The workflow keeps the author in control: revise the text, approve the exact
version, review the visual, and publish only through a protected final action.
The current private beta has completed three consecutive daily publication cycles
through the official LinkedIn API.

Praeco is being prepared for a safe public-source release. Its planned Publisher
extension point can support future official adapters such as Telegram Channels,
Instagram Professional, and Facebook Pages. Those integrations are roadmap items,
not current features.
